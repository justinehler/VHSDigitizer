# Privacy

VHS Digitizer uses local macOS camera/capture-device and microphone/audio-device access so it can preview and record media from a connected capture device.

- Video and audio are processed locally on the Mac.
- Recordings are saved only to the output folder selected by the user.
- Metadata entered in the app is embedded into the movie file and written to the JSON sidecar next to the recording.
- The app does not require FFmpeg or external command-line tools.
- The app does not include analytics, telemetry, advertising, or network upload behavior.

If network features are added in the future, this document should be updated before release.
